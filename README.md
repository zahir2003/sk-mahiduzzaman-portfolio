# Sk Mahiduzzaman — Dynamic 3D AI/ML Portfolio

A dark-first, recruiter-focused Next.js portfolio with a 3D photo hero and polished light/dark visual modes.

## Highlights
- Neon `Sk` identity treatment
- Animated role/typewriter display
- Mouse-responsive 3D portrait tilt
- Luminous cyan/lime ambient lighting
- 3D depth layer, orbit rings, floating chips and scan line
- Scroll reveal animations
- Hover interactions across navigation, buttons, projects, skills and timeline
- Light/Dark mode toggle with saved preference
- Embedded resume viewer + direct PDF download
- SEO metadata + Person JSON-LD
- Responsive desktop/tablet/mobile layouts
- Compatible with the Next.js 16 setup used by the current project

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```
